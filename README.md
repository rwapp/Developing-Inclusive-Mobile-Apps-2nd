# Developing Inclusive Mobile Apps — 2nd Edition: Sample Code

This repository contains the sample code projects for the second edition of *Developing Inclusive Mobile Apps*.

## Exercises

| Exercise | Platform | Topic |
|----------|----------|-------|
| [exercise_4-1](exercise_4-1/) | Android | Accessibility Tree service |
| [exercise_4-2](exercise_4-2/) | Android | Semantic views in Jetpack Compose |
| [exercise_6-1](exercise_6-1/) | iOS | Semantic views in SwiftUI |

## Requirements

### Android projects (exercises 4-1, 4-2)
- Android Studio
- Min SDK: 28 (Android 9 / Pie)
- Target SDK: 36 (Android 16)
- Java 11

### iOS projects (exercise 6-1)
- Xcode
- Min deployment target: iOS 26.2
- Swift 5.0
